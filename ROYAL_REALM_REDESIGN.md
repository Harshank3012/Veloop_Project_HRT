# VELOOP Royal Realm redesign

This pass implements the supplied Level-Up Dashboard assignment reference using the existing React/Vite application.

## Updated
- Reworked the Level Dashboard hero into a royal player-intro with a rank emblem, progression-oriented copy and in-page calls to action.
- Applied a restrained deep-navy, champagne-gold and muted-violet design system across the dashboard, navigation, missions, streaks, activity, badges, Watch & Earn and XP Catcher surfaces.
- Refined card borders, surfaces, typography, focus states, hover feedback and responsive hero layout.
- Preserved the existing rank-emblem image assets, XP persistence, badge unlocks, activity tracking, route structure and XP Catcher gameplay logic.
- Kept demo reward wording and existing earning feature availability/Coming Soon states.

## Run locally
1. Open either the repository root or `Veloop_Project_demo` (both source trees are synchronized).
2. Run `npm install`.
3. Run `npm run dev`.

## Verification
Source and ZIP structure were checked. A production build could not be run in the creation environment because Vite dependencies were not available after dependency installation timed out. Run `npm run build` locally before deployment.
