# VELOOP rank badge transparency update

The rank emblem PNGs have been cleaned to remove the dark matte connected to the image edges. The original badge artwork, wings, gemstones, pedestal and glow are retained.

This repository contains two app copies, and both asset folders are updated:
- `src/assets/rank-emblems/`
- `Veloop_Project_demo/src/assets/rank-emblems/`

## Deploy to Vercel
1. Extract this ZIP and open the app folder configured in Vercel.
2. Confirm the Vercel Root Directory is the intended app folder (`Veloop_Project_HRT` or `Veloop_Project_HRT/Veloop_Project_demo`).
3. Run `npm install` and `npm run build` in that app folder.
4. Commit and push the updated files, then redeploy.

If the old artwork still appears, check Vercel's Root Directory and trigger a fresh deployment. Clear the build cache if needed.
