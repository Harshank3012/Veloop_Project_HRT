# Perfect Circle Hero Frame

Updated the dashboard hero's outer gold halo in `src/components/LevelDashboard/LevelDashboard.module.css`.

- Explicit 1:1 aspect ratio, border-box sizing and 50% border radius.

- Keeps the original badge artwork, rank emblem, halo colors and glow styling unchanged.

Build with `npm ci` then `npm run build` from the project root before deploying.
