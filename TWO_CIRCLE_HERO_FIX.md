# VELOOP Hero — Exactly Two Circles

## Root cause fixed
The extra circles were not coming from the SVG halo. They were generated by the `sphericalOrbit` span rendered by `RankEmblem.jsx`, plus its CSS border and `::before` / `::after` rings in `RankEmblem.module.css`.

## Changes
- Removed the `sphericalOrbit` span from the hero RankEmblem.
- Removed the sphericalOrbit border, pseudo-element rings and associated orbit animations.
- Kept exactly two SVG `<circle>` elements in the hero:
  1. `heroHaloOuter`: solid golden circle with glow from the SVG filter.
  2. `heroHaloOrbit`: dotted golden circle.
- Kept the original badge artwork, rank colors, pedestal, and RankEmblem artwork sizing unchanged.

## Files changed
- `src/components/LevelDashboard/RankEmblem.jsx`
- `src/components/LevelDashboard/RankEmblem.module.css`

The existing two-circle SVG in `src/components/LevelDashboard/LevelDashboard.jsx` and its styling in `LevelDashboard.module.css` are retained.

## Deploy
Run `npm ci` and `npm run build` from the project root before deploying.
